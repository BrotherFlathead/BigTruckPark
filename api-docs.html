API Reference

Integrate BigTruckPark AutoPost into your own applications with our RESTful API. All endpoints return JSON and require authentication.

Overview

The BigTruckPark API provides programmatic access to your social media automation workflows. Use it to upload posts, retrieve analytics, manage connected accounts, and configure scheduling.

Base URL: https://api.bigtruckpark.com/v1

All requests must be made over HTTPS. Responses are returned in JSON format.

Authentication

API requests are authenticated using Bearer tokens in the Authorization header. Include your API key as follows:

Authorization: Bearer sk_live_xxxxxxxxxxxxx

You can generate API keys from your account dashboard. Keep your keys secure and never share them publicly.

HeaderRequiredDescription
AuthorizationYesBearer token (API key)
Content-TypeYesapplication/json

Posts

POST/posts

Create a new post. You can specify the content, platform, and scheduling options.

Request Body

ParameterTypeRequiredDescription
video_urlstringYesURL of the video file to post
platformstringYesTarget platform (e.g., "tiktok", "youtube")
account_idstringYesConnected account identifier
titlestringNoPost title (auto-generated if omitted)
hashtagsarrayNoList of hashtags (auto-generated if omitted)
schedule_atstringNoISO 8601 timestamp for scheduled posting

Example Request

curl -X POST https://api.bigtruckpark.com/v1/posts \
  -H "Authorization: Bearer sk_live_xxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "video_url": "https://cdn.example.com/videos/my-video.mp4",
    "platform": "tiktok",
    "account_id": "acc_abc123",
    "hashtags": ["viral", "trending", "fyp"]
  }'

Example Response

{
  "id": "post_xyz789",
  "status": "queued",
  "platform": "tiktok",
  "created_at": "2026-05-07T09:00:00Z",
  "scheduled_at": null,
  "estimated_completion": "2026-05-07T09:05:00Z"
}
GET/posts/{id}

Retrieve the status and details of a specific post.

GET/posts

List all posts with optional filtering by status, platform, or date range.

Analytics

GET/analytics/overview

Get aggregated analytics across all connected accounts: total views, followers, engagement rate, and post count.

GET/analytics/posts/{id}

Get detailed performance data for a specific post: views, likes, comments, shares, and watch time.

GET/analytics/trends

Get trending insights about optimal posting times, hashtag performance, and content format preferences.

Accounts

GET/accounts

List all connected social media accounts with their current status and platform details.

POST/accounts

Connect a new social media account via OAuth. Returns a redirect URL for authorization.

DELETE/accounts/{id}

Disconnect and remove a connected account.

Scheduling

GET/schedule

Get the current posting schedule and optimal time recommendations.

POST/schedule/optimize

AI-powered optimization: analyzes audience engagement patterns and returns recommended posting times for each connected account.

Rate Limits

API requests are rate-limited to protect the platform from abuse. Limits vary by plan:

PlanRequests/minRequests/day
Free301,000
Pro12010,000
Enterprise600Unlimited

Rate limit headers are included in every response. If you exceed your limit, you'll receive a 429 status with a Retry-After header indicating when to retry.
